# 🛡️ PhishGuard – Phishing URL Detection System

PhishGuard is a machine learning-based web application that analyzes URLs and helps identify potentially malicious or phishing websites. It uses a trained machine learning model to classify URLs and provides users with a risk assessment through a simple web interface.

## 🚀 Features

- **URL Analysis:** Accepts a URL for security analysis.
- **Machine Learning Detection:** Uses a trained model to classify potentially suspicious URLs.
- **Trusted Domain Recognition:** Checks configured trusted domains before performing further analysis.
- **Risk Assessment:** Displays a risk category and score based on the application's detection logic.
- **Web Interface:** Provides an interactive interface built with HTML and CSS.
- **Flask Backend:** Connects the user interface to the detection model.

## 🧰 Technologies Used

- **Programming Language:** Python
- **Backend:** Flask
- **Machine Learning:** Scikit-learn
- **Feature Extraction:** Character-level TF-IDF
- **Model:** SGDClassifier
- **Model Persistence:** Joblib
- **Frontend:** HTML5, CSS3
- **Development Tools:** VS Code,
